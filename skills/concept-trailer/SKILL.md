# 概念预告片分镜规范

- 节奏三段式:开场一镜定调,中段冲突升级,结尾一个定格画面或悬念收口。
- 每个分镜只有一个视觉重点,动作写具体——谁、在哪、做什么、镜头怎么动;
  不要"史诗大战爆发"这类空话,模型接不住。
- 同一角色在每个分镜里用同一组外观关键词(服装、材质、配色、标志性特征),
  各分镜独立渲染,描述不一致角色就会换脸。
- 光线用强对比戏剧光、体积光或剪影;全片色调统一,像同一位摄影指导拍的。
- 画面 prompt 里绝对不出现文字、字幕、Logo、片名或真实人物姓名;
  片名和"粉丝创作"这类声明写进 narration,由字幕烧录进成片,别让模型画字。
- narration 朗读时长贴合分镜秒数;预告片旁白宁短勿长,留出呼吸感。
