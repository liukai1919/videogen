# 外部视频下载功能计划

目标：在本地工作台输入一个或多个公开网页视频链接，查看标题和可用清晰度，按 MP4 或 MP3 下载，持续查看任务进度并取回文件。

范围：新增独立下载任务模块、HTTP API、工作台入口及离线测试。沿用项目已安装的 yt-dlp，不更改现有字幕抓取、渲染和资产接口。第一版最多一次提交 10 条链接，同时执行 2 个下载；不将视频塞进只支持图片的资产中心。

实现步骤：
1. 后端：URL 校验、元数据解析、持久化任务、限并发下载、进度、取消、重试与文件服务。
2. 工作台：多链接去重、元数据和清晰度选择、任务列表及下载按钮。
3. 验证：以假下载器进行离线 API 测试，检查失败、取消、重启后状态；运行相关回归。

验收标准：公开 URL 可获取格式；重复 URL 不产生重复提交；MP4/MP3 各能创建任务；任务状态、进度可查；完成后可下载；失败可重试、运行中可取消；非法/本地地址拒绝；服务重启后记录可读，未完成任务标记中断。

任务归属：liukai1919/videogen。仓库现有 Issue 中没有同类任务；GitHub Projects 权限不足，暂用 Issue 记录状态。

优先级：P1。依赖：本仓库现有工作台与 yt-dlp 依赖。执行状态以主 Issue #6 和子任务 #7、#8 为准。
